## 2. Technical support

If you experience a problem when using ArcanaLogic, you can write to us for help.

We can help with questions about matters such as:

- Accessing the application and managing your profile.
- How tarot readings, Yes/No consultations and horoscopes work.
- Subscription plans, features and usage limits.
- Technical problems, errors or difficulties using the application.
- Advertising and rewarded ads.

To help us assist you, we recommend describing the problem and, where useful, providing your device, application version and the steps to reproduce it.

**Do not send passwords, access codes, authentication tokens or unnecessary personal information.**
